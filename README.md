# Chosen: Side Hustle Coach

Expo (SDK 57) + React Native + TypeScript app.

- **Phase 1:** navigation, design system, English/Polish, every screen with sample data.
- **Phase 2:** Supabase database (row-level security), Sign in with Apple / Google, onboarding (18+ gate → consent → 16 questions → 30-day lock), account deletion.
- **Phase 3:** slot machine physics, haptics and sounds; result sheet; commitment sheet; 30-day lock with fun spins, free switch after 30 days, Fast Pivot and Elite second slot; 1080×1920 share cards with referral QR code.
- **Phase 4:** 12-week roadmaps for all 15 hustles (EN + PL) with steps that unlock in order; weekly check-ins with screenshots; XP, levels (100·n^1.5), streaks, profit ranks, 9 badges; celebrations; Progress with profit chart and "Top X%" (only for groups of 50+). All rewards are decided by the database, never by the app.
- **Phase 5:** AI coach chat (Claude Sonnet 5, prompt caching, screenshots, monthly limits 150/400 + bonus), coach analysis of every Pro/Elite check-in, AI-personalized roadmaps, admin-generated draft roadmaps, and a daily push (Haiku line for Pro/Elite, a random stored line for Free, nudges after 8+ days without a check-in). All Claude calls happen in Supabase Edge Functions.
- **Phase 6:** purchases with RevenueCat. Pro and Elite subscriptions (monthly/yearly, 3-day Pro trial) on a paywall driven by RevenueCat Offerings, Fast Pivot and 100-message packs (bonus messages never expire), Restore Purchases, a webhook + sync function that set the plan and credits on the server, referral rewards, and Apple's rating prompt after positive moments only.
- **Phase 7:** PostHog analytics (EU, only after consent, masked session replay), notification permission after choosing a hustle with an explanation first, a separate opt-in for offers and an admin tool to send them, Terms / Privacy / AI / affiliate screens, "Not financial advice" notices, AI consent withdrawal, data download, offline / loading / error states, Dynamic Type and VoiceOver improvements, email sign-in for the App Review demo account, and the App Store checklist.

**Setup guides, in order:** [SETUP-BACKEND.md](docs/SETUP-BACKEND.md) → [SETUP-PAYMENTS.md](docs/SETUP-PAYMENTS.md) (App Store Connect, RevenueCat, TestFlight) → [SETUP-ANALYTICS.md](docs/SETUP-ANALYTICS.md) (PostHog, funnels, dashboards) → [APP-STORE-CHECKLIST.md](docs/APP-STORE-CHECKLIST.md) (submission). Legal drafts for your website: [docs/legal/](docs/legal/). Until `.env` has your Supabase keys, the app runs in **preview mode** (sign-in and purchases are simulated and data stays on the device).

## See it on your iPhone

1. On your iPhone, install **Expo Go** from the App Store.
2. On this PC, open PowerShell in `C:\Firma\APKA\chosen` and run:

   ```bash
   npx expo start
   ```

3. Scan the QR code shown in PowerShell with the iPhone Camera app. It opens in Expo Go.
   - Your phone and PC must be on the same Wi-Fi. If they can't be, run `npx expo start --tunnel` instead.
4. To stop the server, press `Ctrl + C` in PowerShell.

You can also preview in a web browser by pressing `w` after `npx expo start`. The web version is only a quick preview; the real target is the phone.

## Where things live

| Folder | What's inside |
| --- | --- |
| `src/app/` | Screens. Every file is a route (Expo Router). `(onboarding)/` = welcome → draw → reveal → commit (sign-in) → age → consent → quiz/1…16 → commit (lock in). `(tabs)/` = Today, Roadmap, Coach, Progress, Profile. |
| `src/components/ui/` | Design system: Button, Card, Chip, BottomSheet, ProgressBar, StatTile, EmptyState, Text, Toggle, Checkbox, Segmented… |
| `src/theme/tokens.ts` | All colors (dark + light), fonts, spacing, radii. Change the look here. |
| `src/i18n/locales/` | `en.json` and `pl.json`, all UI text. Keep both files in sync (`npm run check:i18n`). |
| `src/lib/supabase.ts`, `src/lib/auth.ts` | Supabase client (URL + public key only) and Apple/Google sign-in. |
| `src/state/AccountProvider.tsx` | Signed-in user: profile, committed hustle, sign-out, account deletion. |
| `src/data/hustles.seed.json` | The 15 hustles (EN + PL). Same data as the database seed (`npm run seed:hustles`). |
| `src/data/quiz.ts` | The 16 onboarding questions. |
| `supabase/migrations/` | The SQL you paste into Supabase, in order (tables, security rules, machine rules, seed data). |
| `src/components/machine/` | Machine screen, result sheet and commitment sheet. `src/lib/reelPhysics.ts` tunes the reel motion. |
| `src/components/share/StoryCard.tsx` | The 9:16 share cards. |
| `assets/sounds/` | Machine sounds, generated by `npm run sounds` (edit `scripts/generate-sounds.js` to tweak them). |
| `src/config.ts` | Invite link used in share-card QR codes (placeholder, replace before launch). |
| `supabase/functions/delete-account/` | Server function that deletes a user's files, account and all data. |
| `src/data/roadmaps/` | The 15 base roadmaps (one JSON file per hustle, English + Polish side by side) and `affiliate-links.json`. `npm run seed:phase4` checks them and writes the SQL seed. |
| `src/lib/progression.ts`, `src/lib/money.ts` | Level formula, ranks, streak days, check-in schedule, currency conversion (the same rules the database uses). |
| `src/state/ProgressProvider.tsx` | Steps, check-ins, badges and active days; sends "step done" and check-ins to the server. |
| `src/state/RewardsProvider.tsx`, `src/components/RewardToast.tsx` | "+XP" celebrations, badge toasts, and the full-screen rank-up / roadmap-complete screen. |
| `supabase/functions/refresh-exchange-rates/` | Daily exchange rates (ECB, free) so ranks work in every currency. |
| `supabase/functions/_shared/chosen.ts` | Code shared by the 5 AI functions: Claude calls, the coach prompt, user context, roadmap checks. `npm run sync:functions` copies it into each function. |
| `supabase/functions/coach-chat/` … `daily-motivation/` | The AI Edge Functions (coach chat, check-in feedback, roadmap personalization, draft roadmaps, daily push). |
| `src/state/useCoach.ts`, `src/app/(tabs)/coach.tsx` | The coach chat in the app. |
| `src/app/admin.tsx` | Admins: generate, preview and approve draft roadmaps. |
| `src/lib/notifications.ts` | Push permission, Expo push token, opening the right screen from a push. |
| `src/app/paywall.tsx` | The paywall (Pro vs Elite, monthly/yearly) and the Fast Pivot / 100-message purchase screens. |
| `src/lib/plans.ts`, `src/lib/purchases.ts`, `src/state/PurchasesProvider.tsx` | Prices from RevenueCat Offerings, the Apple purchase sheet, Restore, and asking the server to confirm a purchase. |
| `src/lib/paywall.ts`, `src/state/usePaywallTriggers.ts` | Where the paywall opens (end of onboarding, Coach for Free users, first check-in, Elite features, Fast Pivot). |
| `src/lib/review.ts` | Apple's rating prompt after a rank-up, first revenue or a finished roadmap (max once per 90 days, never tied to a reward). |
| `supabase/functions/revenuecat-webhook/`, `supabase/functions/sync-purchases/` | The server side of purchases: plan, credits and referral rewards, checked with RevenueCat's secret key. Shared code: `supabase/functions/_shared/purchases.ts`. |
| `src/config.ts` | **Placeholders to replace:** website, Terms, Privacy, support email, invite link. Also RevenueCat keys from `.env`. |
| `eas.json` | Cloud build settings for TestFlight / App Store (`npx eas-cli@latest build`). |
| `src/lib/analytics.ts`, `src/state/useAnalyticsBridge.ts` | PostHog: consent handling, identify by user ID, screen views, app opens. Events are sent with `track(…)` from the screens. |
| `src/app/push-intro.tsx` | "Your coach, once a day": explains notifications before the iPhone asks. |
| `src/app/legal.tsx` | Terms, Privacy, AI and affiliate summaries with links to your website. |
| `src/app/email-sign-in.tsx` | Email sign-in for existing accounts (the App Review demo account). |
| `src/lib/exportData.ts` | Profile → Download my data (JSON). |
| `src/components/OfflineBanner.tsx`, `src/components/StateCards.tsx`, `src/lib/network.ts` | Offline pill, "can't connect" screen, loading and error cards. The last account and progress data are kept on the phone so the app opens offline. |
| `src/components/admin/PromoComposer.tsx`, `supabase/functions/promo-push/` | Admins send "Offers & news" pushes (opt-in only). |
| `supabase/demo/demo-account.sql` | Fills the App Review demo account with realistic data. |
